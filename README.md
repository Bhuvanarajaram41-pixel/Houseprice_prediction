# House Price Prediction using Machine Learning

## Project Description
This project predicts house prices using Machine Learning techniques. The model was built using Linear Regression in Scikit-learn.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Workflow
1. Loaded the Housing dataset
2. Preprocessed the data
3. Encoded categorical variables
4. Performed correlation analysis using a heatmap
5. Split the data into training and testing sets
6. Trained a Linear Regression model
7. Evaluated the model using R² score

## Result
- R² Score: 0.64
